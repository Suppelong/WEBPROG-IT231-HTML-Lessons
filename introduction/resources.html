Resource Documentation

This page lists all frameworks, libraries, and tools used to create this personal resume website, in accordance with the project requirements.

Category Resource Name Link / Source Usage Description
CSS Framework Bootstrap 5 getbootstrap.com Used for the responsive grid system, navbar, cards, and responsive utilities (Flexbox).
JavaScript Framework Vue.js 3 vuejs.org Used to create dynamic components for the Picture Gallery and the Guestbook/Survey form.
Icons Bootstrap Icons icons.getbootstrap.com Used for social media logos in the footer (LinkedIn, Github, Facebook, Instagram).
Fonts Google Fonts (Poppins) fonts.google.com Used to improve typography and aesthetic design beyond the default Bootstrap fonts.
AI Assistance Google Gemini gemini.google.com Used to generate code structure for Vue.js components, debug CSS alignment, and organize file structure.
Images Personal/Stock Local Folder Images used in the gallery representing personal projects and interests.
